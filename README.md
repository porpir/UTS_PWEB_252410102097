# UTS Pemrograman Web - Kedai Minuman Nusantara

Repository ini berisi proyek aplikasi web sederhana berbasis arsitektur MVC menggunakan framework Laravel. Aplikasi ini mengelola data menu dan inventaris kedai minuman secara statis melalui controller tanpa menggunakan database.

## Fitur Aplikasi
1. Simulasi Login: Meneruskan username pengguna ke halaman Dashboard dan Profile melalui Request Parameter.
2. Dashboard: Menampilkan statistik varian produk dan stok yang dikirim langsung dari PageController.
3. Halaman Pengelolaan: Menampilkan daftar tabel inventaris minuman menggunakan perulangan array Blade (@foreach).
4. Halaman Profil: Menampilkan ringkasan akun pengelola aktif.
